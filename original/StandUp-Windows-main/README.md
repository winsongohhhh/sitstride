# 🧍 StandUp (站一会儿)

A lightweight Windows VBScript tool that reminds you to take regular standing breaks during long work sessions.

一款轻量级 Windows 久坐提醒工具，通过 VBScript 实现，帮助你在长时间办公时定时起身，培养更健康的工作习惯。


## Features / 功能

- Reminds you to take regular standing breaks  
  定时提醒你起身活动

- Lightweight and easy to use  
  轻量、简单易用

- No installation required  
  无需安装，下载即可运行


## Usage / 使用方法

1. Download `StandUp.vbs`
   
   下载 `StandUp.vbs`

2. Double-click the file to run the script
   
   双击文件运行脚本

3. Keep the script running while working
   
   工作期间保持脚本运行即可

4. To change the timing, right-click and open `edit`, then modify the numbers on lines 3 and 4

   如需修改时间，右键点击 `edit`（编辑）打开，修改第 3、4 行的数字即可

5. To stop the timer midway, double-click the `Stop_Timing.vbs` file to terminate it

   如需中途停止计时，使用 `Stop_Timing.vbs` 文件，双击即可终止


## Technology / 技术实现

Built with Windows VBScript.

基于 Windows 内置 VBScript 实现，无需额外安装运行环境。
