## Short promotional copy

## Longer launch copy

Long stretches at your desk can make it easy to forget a break. SitStride is a Windows system-tray break timer with a simple rhythm: a sitting countdown, a “Time to stand up” reminder, and a standing-break timer you control.

Start with 60 minutes sitting and 5 minutes standing, or choose your own intervals. Pause when needed, snooze a due sitting reminder for five minutes, and enable reminder sound or run on startup. An animated mascot changes posture with you, with a reduced-motion option when you prefer less movement. Settings stay local; the app has no telemetry or automatic updater.

Version 1.0.7 is an unsigned test candidate for Windows 10/11 x64, not a Windows-validated production release. Static/source and packaged-Linux checks passed; native Windows installation and behavior still need testing. It does not track steps or make medical claims.
