## Short promotional copy

Meet SitStride, a stand up reminder and sitting reminder for Windows that helps you remember to leave your chair. Set your sitting and standing intervals, pause or snooze a reminder, and keep an animated mascot nearby in the system tray. It can be a simple desk break reminder for a calmer workday.

SitStride 1.0.7 is an unsigned, x64-only test build for Windows 10/11. Windows may show a SmartScreen or unknown-publisher warning. Static/source and packaged-Linux checks passed, but the installer and native Windows behavior have not been tested on Windows. The 250-step prompt is a suggestion, not step tracking.

## Longer launch copy

Long stretches at a desk can make it easy to forget a break. SitStride is a Windows system-tray break timer—a customizable stand up reminder, sitting reminder, and desk break reminder—with a simple rhythm: a sitting countdown, a “Time to stand up” prompt, and a standing-break timer you control.

Start with 60 minutes sitting and 5 minutes standing, or choose your own intervals. Pause when needed, snooze a due sitting reminder for five minutes, and enable reminder sound or run on startup. An animated mascot changes posture with you, with a reduced-motion option when you prefer less movement. Settings stay local; the app has no telemetry, automatic updater, or application network requests.

Version 1.0.7 is an unsigned, x64-only test candidate for Windows 10/11, not a Windows-validated production release. Installation and native Windows behavior still need testing. The 250-step prompt is only a suggestion; SitStride does not track steps and makes no medical claims.
